# Visual Style Guide

Player setup screens use a warm, printed-paper palette and bold editorial typography to match the retro character artwork.

## Palette

| Purpose | Color |
| --- | --- |
| Page background | Paper cream `#F5EBD1` |
| Unselected card | Ivory `#FCF8EB` |
| Main text and outlines | Deep brown `#2E2119` |
| Supporting text | Muted brown `#6B5E52` |
| Selected state and primary action | Tomato red `#C73812` |
| Selected card | Golden yellow `#E89E14` |
| Disabled action | Warm gray `#ADA99E` |

## Typography

- Use a bold serif for screen titles, character names, and primary actions.
- Use a simple rounded system sans-serif for supporting instructions.
- Keep headings large and high contrast; allow longer titles to wrap.

## Components

- Character cards use the supplied illustrated portraits, rounded corners, and a dark outline.
- Show selection with both a golden card fill and a tomato-red outline; add a “YOU” badge so selection is not communicated by color alone.
- Primary actions span the available width and retain a dark outline. Disabled actions use warm gray.
- Keep the action anchored at the bottom while the character grid scrolls.

## Artwork

Use the existing `avt-1` through `avt-6` image assets for the mock player roster. Keep the original illustrations intact and use `scaledToFit` so the portraits are not distorted.
